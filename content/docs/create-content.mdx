# Author Documentation Pages

Create and edit documentation pages in the `content/docs/` folder. Each page is a Markdown file with a `.mdx` extension.

## Add documentation pages

<Steps>
  <Step title="Create the page files">
    Create the document files under `content/docs/` for the new pages with the type `.mdx`.
  </Step>

  <Step title="Add frontmatter and content">
    In each new page, add a frontmatter block with a title and description:

    ```md
    ---
    title: A title for the page
    description: A short, specific summary of what this page covers.
    ---
    ```

  </Step>

  <Step title="Add the page to the navigation">
    In `content/nav.config.ts`, add an entry for the new page to the `items`
    array of a group, such as **Get Started**. For example:

    ```ts
    { title: "My Page", href: "/my-page" }
    ```
  </Step>

  <Step title="Frontmatter fields">
    Every file in `content/docs/` supports the following frontmatter fields:

  | Field         | Type   | Required | Description                                  |
  | ------------- | ------ | -------- | --------------------------------------------- |
  | `title`       | string | yes      | Used as the page `<title>` and page heading.  |
  | `description` | string | yes      | Used for the meta description and search.     |
  
  </Step>
</Steps>

## Update navigation

Add the new pages to `content/nav.config.ts` to update the navigation structure. 

`content/nav.config.ts` exports a list of groups, each with a title and an ordered list of items.

For example: 

```ts
export const nav: NavGroup[] = [
  {
    title: "Get Started",
    href: "/",
    items: [
      { title: "Introduction", href: "/" },
      { title: "Quickstart", href: "/quickstart" },
    ],
  },
  {
    title: "Release Notes", href: "/release-notes",
    items: [],
  },
];
```

## Add your product logo

By default, the top bar shows the Beacon logo next to your product name. To
show your own logo instead, add an image file named `logo` to the `content/`
folder, such as `content/logo.svg`. Supported file types are `.svg`, `.png`,
`.jpg`, `.jpeg`, and `.webp`.

To show a different logo in dark mode, also add a file named `logo-dark`, such
as `content/logo-dark.svg`. If you don't add one, the site shows your `logo`
file in both modes.

The top bar displays the logo 24 pixels high and scales the width to match.
For the sharpest result, use an SVG file. Keep only one `logo` file and one
`logo-dark` file in `content/`, or the build fails.

The development server reads the logo when it starts, so restart it after you
add or change the logo.

## Run the development server

<Steps>
  <Step title="Start the development server">
    Start a local development server to preview your changes as you edit your pages:

    ```bash
    npm run dev
    ```
  </Step>

  <Step title="View the content pages">
    View the new pages at
    [http://localhost:3000](http://localhost:3000).

    The development server does not write the site to the `out/` directory.

    Changes to `content/nav.config.ts` reload automatically. To see changes to
    `.mdx` files, refresh the browser.
  </Step>

  <Step title="Stop the development server">
    Press `Ctrl+C` to stop the development server.
  </Step>
</Steps>
