# Install {{productName}} 

Install {{productName}} on your local machine.

<Steps>
  <Step title="Create the site project">
    Create a new project, `<my-project>`:

    ```bash
    npm create beacon-docs@latest <my-project>
    ```
  </Step>

  <Step title="Specify the project and product names">
    When prompted, specify:

    * `<my-project>`: The project name

    * `<my-product>`: The product name that this documentation describes

  </Step>

  <Step title="Review what the command does">
    The command performs the following tasks:

    1. Downloads {{productName}}.

    1. Adds starter pages.

    1. Saves the product name in `.env.local`.

    1. Creates a local Git repository with an initial commit.

    1. Installs the dependencies.
  </Step>

  <Step title="Change to the project directory">
    ```bash
    cd <my-project>
    ```
  </Step>
</Steps>
