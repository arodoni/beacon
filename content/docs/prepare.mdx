# Prepare

Before you install and configure Beacon, get a local copy of the project. See
[Requirements](/quickstart#requirements) for the tools you need.

## Clone the repository

1. Clone the Beacon repository from GitHub:

   ```bash
   git clone https://github.com/arodoni/beacon.git
   ```

1. Change to the project directory:

   ```bash
   cd beacon
   ```

Run all later commands, such as `npm install`, from this directory. For the
next steps, see [Install and run Beacon locally for live
preview](/quickstart#install-and-run-beacon-locally-for-live-preview).
