# Prepare

Before you install and configure {{productName}}, get a local copy of the project.

## Requirements

Before you begin, install the following:

- [Node.js](https://nodejs.org/) 20.9.0 or later, the minimum version that
  Next.js 16 supports

- `npm` that is bundled with Node.js

## Clone the repository

1. Clone the {{productName}} repository from GitHub:

   ```bash
   git clone https://github.com/arodoni/{{projectName}}.git
   ```

1. Change to the project directory:

   ```bash
   cd {{projectName}}
   ```

Run all later commands, such as `npm install`, from this directory. For the
next steps, see [Install and run {{productName}} locally for live
preview](/quickstart#install-and-run-beacon-locally-for-live-preview).
