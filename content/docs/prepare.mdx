# Prepare

Before you install and configure {{productName}}, get a local copy of the project.

## Requirements

Before you begin, install the following:

- [Node.js](https://nodejs.org/) 20.9.0 or later, the minimum version that
  Next.js 16 supports

- `npm` that is bundled with Node.js

## Create a site with npm create beacon-docs

To start a new docs site, use `npm create beacon-docs`. The command downloads
{{productName}}, replaces its docs with starter pages, sets your product and
project names, creates a Git repository, and installs dependencies. For the
steps, see [Install and run {{productName}} locally for live
preview](/quickstart#install-and-run-beacon-locally-for-live-preview).
