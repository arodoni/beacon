# Beacon

Beacon is an open-source, self-hosted static site generator for documentation, tutorials, and product content. Write pages in MDX (`.mdx`), which is Markdown with support for JSX components, define your content structure, and Beacon produces plain static HTML, CSS, and JavaScript you can host anywhere.

## What you get

- **Markdown content**: Every page lives in `content/docs/*.mdx` with simple
  frontmatter.

- **Config-driven navigation**: Navigation structure, ordering, and grouping all
  come from `content/nav.config.ts`.

- **Client-side search**: Press <kbd>⌘</kbd> <kbd>K</kbd> (or <kbd>Ctrl</kbd>
  <kbd>K</kbd>) anywhere on the site to fuzzy-search every page, with no
  external search service involved.

- **Syntax highlighting**: Code blocks are highlighted at build time, so no
  client-side JavaScript is required to render them correctly.

- **Dark mode**: A theme toggle in the top bar persists your choice across
  visits.

- **Zero server**: The build output is static files. No Node process, no
  database, no vendor lock-in. Deploy to Vercel, Netlify, GitHub Pages, or any
  static host.

- **Editor**: A live Markdown editor under Tools (`/dashboard/editor`) for
  drafting and previewing formatting before publishing a page.

- **Monitor**: A Tools pane that tracks doc-update suggestions, with status
  badges so you can review, accept, or dismiss each one.
