# Release Notes

This page tracks notable features and changes as they ship, newest first.

## 2026-08-19

- Added a `status` field (`pending`, `accepted`, `dismissed`) to doc-update suggestions. The Observability dashboard now shows a status badge on each suggestion, with Accept/Dismiss buttons for pending ones that call a new `PATCH /api/doc-suggestion-status` endpoint, guarded by a shared secret since the dashboard has no login. See [Doc Update Automation](/doc-updates) for details.

## 2026-08-16

- Added a Dashboard section at `/dashboard`, replacing the standalone `/editor` route. It houses the Markdown editor (now at `/dashboard/editor`) and a new Observability page (`/dashboard/observability`) that lists doc-update suggestions generated by the automation webhook, previously only visible in Blob storage.

## 2026-08-12

- Added a `Callout` component (`src/components/docs/Callout.tsx`) for note, tip, important, and warning admonitions in docs content. It's registered as a global MDX component, so any `.mdx` file can use `<Callout type="warning">...</Callout>` directly without an import statement.

- Added a `DOC_UPDATE_AUTOMATION_ENABLED` environment variable to gate the doc update automation webhook. It's disabled by default; set it to `true` to turn the automation on. See [Doc Update Automation](/doc-updates) for details.

## 2026-08-05

- Added this Release Notes page to track new features going forward.

- Added a GitHub webhook that triggers when a PR merges into `main` touching `content/docs/**/*.mdx` or `content/nav.config.ts`. It checks whether other doc pages are now stale and writes suggestions to Vercel Blob storage for manual review. See [Doc Update Automation](/doc-updates) for details.
