# Quickstart

## Requirements

Before you begin, install the following:

- [Node.js](https://nodejs.org/) 20.9.0 or later, the minimum version that
  Next.js 16 supports

- `npm` (bundled with Node.js)

## Install and run Beacon locally for live preview

1. From the root of your project, install the project dependencies:

   ```bash
   npm install
   ```

1. Start a local development server to preview your changes as you edit the
   content:

   ```bash
   npm run dev
   ```

   The development server runs at
   [http://localhost:3000](http://localhost:3000) and renders each page when
   you request it. It doesn't write the site to the `out/` directory. Changes
   to `content/nav.config.ts` reload automatically. To see changes to `.mdx`
   files, refresh the browser.

## Add a documentation page

1. Create a file under `content/docs/` for the new page, for example
   `content/docs/my-page.mdx`.

1. Add a frontmatter block to the file with a title and description:

   ```md
   ---
   title: My Page
   description: A short, specific summary of what this page covers.
   ---

   # My Page

   This is the content for my page.
   ```

   Beacon picks up the file automatically through the catch-all route and adds
   it to the client-side search index. The build also adds it to the sitemap.

1. To add a link to the page in the navigation, add an entry for the new file
   to a group's `items` array in `content/nav.config.ts`, for example the
   **User Guide** group:

   ```ts
   { title: "My Page", href: "/my-page" }
   ```

1. With the development server running, open
   [http://localhost:3000/my-page](http://localhost:3000/my-page) to view the
   new page.

## Build and preview the static site

Build the site to check it as it will be hosted. Unlike the development
server, a build writes every page to disk as static HTML.

1. Stop the development server with <kbd>Ctrl</kbd>+<kbd>C</kbd>.

1. Build the static site into the `out/` directory:

   ```bash
   npm run build
   ```

   The build pre-renders every page to HTML and writes it, along with minified
   JavaScript, CSS, and static assets, to `out/`. When the build finishes, it
   lists each route it generated.

1. Preview the static output locally:

   ```bash
   npm run start
   ```

   This command serves the files in `out/` as they are, with no development
   server. It doesn't pick up your edits, so run `npm run build` again after
   each change.

1. Open [http://localhost:3000/my-page](http://localhost:3000/my-page) to view
   the static output.
