# Quickstart

## Requirements

Before you begin, install the following:

- [Node.js](https://nodejs.org/) 20.9.0 or later, the minimum version that
  Next.js 16 supports

- `npm` (bundled with Node.js)

## Install and run Beacon locally for live preview

1. Clone the Beacon repository and change to the project directory:

   ```bash
   git clone https://github.com/arodoni/beacon.git
   cd beacon
   ```

1. Install the project dependencies:

   ```bash
   npm install
   ```

1. Start a local development server to preview your changes as you edit the
   content:

   ```bash
   npm run dev
   ```

   The development server runs at
   [http://localhost:3000](http://localhost:3000) and renders each page when
   you request it. It doesn't write the site to the `out/` directory. Changes
   to `content/nav.config.ts` reload automatically. To see changes to `.mdx`
   files, refresh the browser.

## Add a documentation page

1. Create a file under `content/docs/` for the new page, for example
   `content/docs/my-page.mdx`.

1. Add a frontmatter block to the file with a title and description:

   ```md
   ---
   title: My Page
   description: A short, specific summary of what this page covers.
   ---

   # My Page

   This is the content for my page.
   ```

   Beacon picks up the file automatically through the catch-all route and adds
   it to the client-side search index. The build also adds it to the sitemap.

1. To add a link to the page in the navigation, add an entry for the new file
   to a group's `items` array in `content/nav.config.ts`, for example the
   **User Guide** group:

   ```ts
   { title: "My Page", href: "/my-page" }
   ```

1. With the development server running, open
   [http://localhost:3000/my-page](http://localhost:3000/my-page) to view the
   new page.

## Deploy to Vercel

Deploy the site to Vercel to publish it. Vercel builds the site from a GitHub
repository, so you first push your copy of Beacon to a repository that you
own.

1. On GitHub, [create a new repository](https://github.com/new). Leave it
   empty: don't add a README, `.gitignore`, or license.

1. Commit the page that you added, point your local clone at the new
   repository, and push it:

   ```bash
   git add .
   git commit -m "Add my page"
   git remote set-url origin https://github.com/<your-username>/<your-repo>.git
   git push -u origin main
   ```

   Replace `<your-username>` and `<your-repo>` with your GitHub username and
   the name of the repository that you created.

1. In the Vercel dashboard, [import the repository](https://vercel.com/new).
   Leave the build settings at their defaults. Vercel detects the Next.js
   static export automatically.

1. Under **Environment Variables**, add `NEXT_PUBLIC_SITE_URL` and set it to
   your site's URL, for example `https://my-docs.vercel.app`.

1. Click **Deploy**. After the first deployment, every push to `main`
   triggers a new production deployment, and pushes to other branches create
   preview deployments.

1. Open `https://<your-project>.vercel.app/my-page` to view the new page.

To preview the static build locally or deploy to another host, see
[Deployment](/deploy).
